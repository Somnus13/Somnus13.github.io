ESP32-S3 · USB Serial/JTAG

浏览器刷固件

用 Chrome 或 Edge，把板子的 USB 口插上即可。板上没有 BOOT / RESET 键，下载模式由串口复位自动进入。一次写入 bootloader、分区表、应用和 6 MiB 内置字体。

下载应用固件

最近更新：正在读取…

如果按钮不可用：当前浏览器没有 Web Serial，或固件文件还没放进本站 firmware/。

写入内容

0x0bootloader.bin
0x8000partition-table.bin
0x10000Read_Pico.bin（应用）
0x910000builtin.ttf（Aura UI Serif）

注意

首次安装建议擦除。擦除会清掉 ESP 里的 NVS（字体选择、睡眠设置），不会改 PMU 里的 VCOM。

VID 303A / PID 1001。不要用手写地址乱烧；应用必须落在 0x10000。

命令行等价：

python -m esptool --chip esp32s3 -p COMx -b 460800 \
  --before default-reset --after hard-reset write-flash \
  --flash-mode dio --flash-freq 80m --flash-size 16MB \
  0x0 bootloader.bin \
  0x8000 partition-table.bin \
  0x10000 Read_Pico.bin \
  0x910000 builtin.ttf
刷写完成后看串口：出现 Loaded app from partition at offset 0x10000 才算启动成功。
